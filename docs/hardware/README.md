# Hardware

## Status

**No hardware exists for this project.** The [audit](../PROJECT_AUDIT.md#5-hardware-and-pcb-status)
searched the tree, all commits and all deleted paths: there is no schematic, PCB, BOM, netlist,
Gerber or HDL file. Phase 1 therefore documents what the simulation *requires* of a receiver and
does not invent a design.

## Consequence for the software

The boundary with a future receiver is the ABF1 frame. Any hardware able to emit it, or any
driver converting to `IQFrame` objects, can feed the pipeline without other changes.
